\section{Research Questions}

Main: How can a configurable data pipeline combine heterogeneous research-funding data into a consistent, enriched
dataset that non-developers can maintain and adapt to change?

Data generation: What data quality problems arise when combining FFG and FWF data on projects, organizations and
funding, and how can they be overcome with publicly available data?

Architecture: Which architecture lets data pipelines be configured, scheduled, monitored and versioned through a web
interface?

Adaptability and usability: To what extent can domain experts run the pipeline, publish datasets and configure it to
changing source APIs without developer support?
